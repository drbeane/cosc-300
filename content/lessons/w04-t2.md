# Week 4: Projects

**COSC-300/500 Applied AI Essentials** · 4D focus: Discernment

## What you will be able to do

- Set up a project with instructions, reference files, and project memory.
- Explain when a project is better than a one-off chat.

A **project** is a persistent workspace around one body of work. It holds:

- **Instructions** that apply to every chat in the project: your role, the audience, the format, the citation style.
- **Reference files**: a knowledge base of documents the model can draw on.
- **Project memory**: what the model learns across the project's chats, kept separate from your other work.
- **Many chats**, all sharing that context.

## When a project beats a one-off chat

Use a project for work that runs across many sessions with the same sources and the same expectations: a course you're taking, a research paper, a job search, an ongoing client. You set up the context once instead of re-explaining it every time. For a single question, just open a chat.

## Key terms

**Project**: a persistent workspace of instructions, files, and memory around multiple chats. **Project memory**: memory scoped to one project.
