# Week 1 lab and assignment: Three-vendor comparison

**COSC-300/500 Applied AI Essentials** · 4D focus: Delegation

## What you will be able to do

- Compare several tools on the same task and judge which output you would actually use.

## Before the lab

- Claude Academy: **AI Fluency: Framework and foundations**, lessons 1–5.
- Set up your accounts: **Claude Pro**, your Maryville **Copilot Chat**, and a free **NotebookLM** account.
- Install the **Claude desktop app**.
- Choose a realistic task from your own coursework or job to use in the lab.

## Lab: one task, five runs

This lab is the start of your first assignment.

1. Pick a realistic task from your own coursework or job. Good tasks have a clear purpose and something you can judge: summarize a reading for a specific audience, draft an email that has to strike a careful tone, explain a concept from your major, plan a week of study.
2. Run it on **three chat tools**: Claude, Copilot Chat, and one free tool (ChatGPT Free, Gemini, or another).
3. Run it on **two Claude models or effort levels** (for example, Sonnet and Opus, or the same model with and without extended thinking).
4. Save every prompt and every output.

As you go, compare the outputs on:

- **Accuracy**: is it right?
- **Usefulness**: would you actually use it?
- **Speed**
- **Format and tone**
- **What each tool could and couldn't do**: did it search the web, read your file, handle the length?

Start your comparison table during the lab.

## Share-out

We'll close by comparing notes: Which output would you actually use? Where did the tools differ most? Did the bigger model or the higher effort setting help, or did it just take longer?

## Assignment: Three-vendor comparison

Run one realistic task from your own coursework or job on three chat tools and on two Claude models or effort settings.

**Submit:**
- A one-page comparison table.
- A 400-word evaluation: which output you would actually use, why, and what the differences suggest about the tools.
- All the prompts you used.

**500 extension:** add a short section relating your observations to one published model card or system card.

**Estimated time:** 3 hours.
