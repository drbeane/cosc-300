What to notice

    
    
      
  1. The model never runs anything. It replies with a request, stop_reason: "tool_use", and your program decides whether to act.
    2. 
      
  2. The model keeps no memory between calls. Every request resends the whole conversation so far, including the tool request and its result.
    3. 
      
  3. The general question gets a direct answer with no tool call. A good description tells the model when to use the tool and when not to.
    4. 
      
  4. In the furlong question the tool returns an error, so the model changes its approach and calls the tool again. An agent is this loop repeated until the job is done.
    5. 
      
  5. Set the description to vague and ask the 5-mile question again. The model skips the tool and answers from memory, which may be close but isn't exact.
    6. 
    

    
The message format follows Anthropic's Messages API (tool_use and tool_result content blocks). Other vendors use similar but not identical formats. The model's replies are scripted for teaching; a real model's wording and choices will vary.
