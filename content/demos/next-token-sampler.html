Next-Token Sampler

A language model writes one token at a time. At each step it scores every possible next token, turns the scores into probabilities, and draws one at random. Change the settings and watch how the draw changes, and why the same prompt can give a different fact on a different run.

What to notice

  1. At temperature 0 the model always takes the top token, so every run is identical. Identical is not the same as correct: it is just the most likely answer, repeated.
  2. At the default setting, most runs share a structure but differ in wording, and some differ on the death toll. If a fact changes between runs, at least one run is unreliable.
  3. Raise the temperature and low-probability tokens, including wrong ones like "mosquitoes," start to appear. Lower top-p and the long tail is cut off before the draw.
  4. The model never "looks up" the death toll here. It picks whichever number is likely to come next. That is why you check facts against a source.

This is a teaching model with hand-set scores and multi-word tokens, not a real LLM. Real models choose from about 100,000 tokens at every step. Fact labels use the CDC's figures: about 500 million infected (roughly a third of the world's population) and at least 50 million deaths.
