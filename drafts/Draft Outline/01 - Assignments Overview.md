# Assignments Overview (draft)

_All assignments in one place. Details, including the COSC-500 extension for each, are in the weekly outlines. Times are rough estimates of out-of-class work for COSC-300._

## Weekly assignments (40%, 12 assignments, lowest dropped)

| Week | Assignment | What students submit | 500 extension | Est. time |
|---|---|---|---|---|
| 1 | Three-vendor comparison | Comparison table, prompts, 400-word evaluation | Relate findings to a published model or system card | 3 h |
| 2 | Prompt revision log | 5 test inputs, 4 prompt versions with outputs, reflection | Rubric scoring of each version | 3 h |
| 3 | Fact-check and failure report | Annotated explainer with sources; two documented failures | Test whether more effort or another model fixes each failure | 3 h |
| 4 | Research brief with citation audit | 2-page brief, 10-citation audit, project vs NotebookLM note | Literature-based discussion of citation reliability | 4 h |
| 5 | Data-to-deliverable package | Report with charts, 5-slide deck, labeled generated image, verification log | Methods appendix | 4 h |
| 6 | Folder-scale delegation task | Task brief, plan with edits, approvals log, outputs, review memo | Minimal vs detailed brief comparison | 4 h |
| 7 | Write and test a skill | Skill files, 3 test runs, change log | Classmate usability test and revision | 3–4 h |
| 9 | First app from a spec | Repository with instruction file, 5+ commits, README, reflection | Same feature with GitHub Copilot Student, compared | 3–4 h |
| 10 | Spec-driven build with tests | Repository, test results per step, review log of 5+ changes | Mid-project requirement change | 4–5 h |
| 11 | First API program with tool use | Code, 3 runs with token usage and cost, explanation of a tool-use round trip | Second vendor or local model | 3–4 h |
| 12 | Mini RAG app, MCP server, or tool evaluation (choose a track) | Build or evaluation, 15+ case test set, results, failure discussion | Model and code grading with agreement check | 4–5 h |
| 13 | Always-on agent field test | Permissions with reasons, multi-day log, 500-word assessment | Comparison with a Claude scheduled task | 3 h |

## Ongoing
- **AI use journal (10%, with reflections).** A short weekly entry: what you delegated, what you checked, what went wrong, what you would do differently. Final 600-word reflection in week 15.
- **Claude Academy courses (10%).** Completion badges for the required courses in the Resource Map, due by the week listed.

## Design notes
- Every assignment requires evidence of review (logs, audits, test results), not just output. This makes AI-written work assessable and teaches the course's central skill.
- Assignments use the student's own coursework, job, or interests wherever possible, so the work is relevant across majors.
- Week 12 has a non-building track so the engineering weeks stay open to students from every major.
- 🔴 Week 13 depends on Muse access (US adults 18+, card at signup). Fallback: students work with an instructor demo account and submit an observation log.
