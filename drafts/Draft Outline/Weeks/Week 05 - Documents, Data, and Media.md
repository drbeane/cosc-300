# Week 5: Documents, Data, and Media

**Surfaces:** Chat assistant [E], Embedded copilot [S] · **Capabilities:** Data analysis with code execution [S], File and document creation [S], Multimodal input [D], Generative media [D] · **4D:** Description

## Goals
Students will be able to:
- Use Markdown, CSV, JSON, and Mermaid as working formats between people and AI.
- Have an AI analyze a dataset by running code, and check the analysis, not only the chart.
- Produce documents, spreadsheets, slides, and simple interactive pages from chat.
- Use images, screenshots, and PDFs as input.
- Use AI inside an application (Copilot in Outlook) and judge when that beats a separate assistant.
- Discuss provenance, deepfakes, and copyright in generated media.

## Class time (two 75-minute meetings)
- 15 min: Structured files. Why Markdown, CSV, JSON, and Mermaid matter (they are also what skills and instruction files are written in, week 7).
- 25 min: Data analysis with code execution. Demo on a messy dataset; show how to read the code the AI ran and catch a wrong aggregation.
- 35 min: Guided practice: the first half of the assignment.
- 15 min: File creation: reports, spreadsheets, slide decks, diagrams. Multimodal input: screenshots, charts, scanned PDFs.
- 10 min: Embedded copilot: Copilot in Outlook on Maryville accounts. What it does well.
- 15 min: Generative media: image generation in brief (a tool other than Claude), provenance and labeling, deepfakes, copyright.
- 35 min: Lab: finish the package.

## Assignment: Data-to-deliverable package
Take a provided or self-sourced dataset (at least 500 rows, with some mess). Have AI clean and analyze it, then produce (1) a 2-page report with charts, (2) a 5-slide summary deck, and (3) one generated image or diagram, labeled as AI-generated. Include a verification log: three numbers you recomputed independently and one error you caught.
- **500 extension:** add a methods appendix explaining each analysis step the AI ran and one alternative analysis you rejected.
- Estimated time: 4 hours.

## Responsible use
What data may be uploaded: FERPA, client and employer data, confidential information.
