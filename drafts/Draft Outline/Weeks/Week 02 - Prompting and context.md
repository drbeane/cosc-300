# Week 2: Prompting and context

**Surfaces:** Chat assistant [E] · **Capabilities:** Memory and custom instructions [D], Voice [D] · **4D:** Description

## Goals
Students will be able to:
- Write prompts that state the goal, context, constraints, audience, and output format.
- Explain tokens and the context window, and list what fills context (system prompt, history, files, tool results, memory).
- Use examples in a prompt and explain why they work (in-context learning, light).
- Iterate a prompt against test inputs instead of tweaking by feel.

## Topics
1. Writing strong prompts
2. Tokens and the context window
3. Memory, custom instructions, and voice
4. Testing and revising prompts
- Lab and assignment: Prompt revision log

## Class time (two 75-minute meetings)
- 25 min: Anatomy of a strong prompt. Clear and direct, specific, structured (headings or XML tags), examples, role and audience. Before-and-after demos.
- 25 min: Context. Tokens, context windows, what context contains, why long chats degrade, starting fresh.
- 25 min: Guided practice. Pairs rewrite three weak prompts, then swap and critique.
- 15 min: Standing context at the account level: memory and custom instructions. What to put there and what not to.
- 10 min: Voice mode demo: when talking is better than typing.
- 40 min: Lab. Build a small test set (5 inputs) for a recurring task and run a prompt through three documented revisions.
- 10 min: Share-out. Which change made the biggest difference?

## Assignment: Prompt revision log
Choose a recurring task (for example, summarizing meeting notes, drafting a cover letter, explaining a concept at two reading levels). Create 5 test inputs. Write a first prompt, then revise it at least three times. For each version, record the prompt, the outputs, and what you changed and why. End with your final prompt and a 300-word reflection.
- **500 extension:** score each version with a simple rubric you define, and report the scores.
- Estimated time: 3 hours.

What memory stores about you; turning it off; reviewing saved memories.
