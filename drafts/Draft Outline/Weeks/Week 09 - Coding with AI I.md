# Week 9: Coding with AI I: The Development Environment

**Surfaces:** Coding assistant in the development environment [E], Local agent [E] · **Capabilities:** Plan mode and autonomy controls [E], Instruction files and skills [E], Usage and context commands [D] · **4D:** Delegation

No prior coding experience is assumed. Students direct the assistant; the skill being taught is specifying, supervising, and checking software work.

## Goals
Students will be able to:
- Set up VS Code, Git, GitHub, and Claude Code, and explain what each does.
- Explain why a coding assistant with access to the repository, terminal, and tests beats copying code from a chat window.
- Use plan mode, permission settings, an AGENTS.md or CLAUDE.md file, and context and usage commands in a repository.
- Commit work in small steps and roll back a bad change.

## Before class

## Topics
1. From Chat Window to Coding Assistant
2. The Development Environment and Claude Code
3. Comparing Coding Assistants
- Lab and assignment: First app from a spec

## Class time (two 75-minute meetings)
- 10 min: Coding in a chat window and its limits.
- 20 min: Tour of the environment. VS Code, the terminal, Git basics (commit, diff, revert), GitHub.
- 15 min: Claude Code in VS Code. Plan mode, permissions, the instruction file, `/context` and `/usage`.
- 30 min: Guided setup clinic and a first small change in a sample repository.
- 10 min: Comparing assistants: Claude Code vs GitHub Copilot Student (agent mode, plan agent, usage allowance).
- 55 min: Lab: build a small app from a short spec.
- 10 min: Share-out. What did the plan get wrong?

## Assignment: First app from a spec
Build a small application from a one-page specification (for example, a personal budget tracker, a flashcard app, or a course-planner web page). Requirements: an instruction file, at least five commits with meaningful messages, and a short README. Submit the repository link and a 300-word reflection on what you reviewed and what you accepted without understanding.
- **500 extension:** build the same feature with GitHub Copilot Student and compare process, quality, and usage consumed.
- Estimated time: 3–4 hours.

## Responsible use
Secrets (API keys, passwords) never in code or chat; licenses of AI-suggested code.
