# Week 6: Local Agents: Delegating Real Work

**Surfaces:** Local agent [E] · **Capabilities:** Plan mode and autonomy controls [E], Usage and context commands [D] · **4D:** Delegation

The centerpiece of the course begins. Students direct an agent (Claude Cowork) that works on a folder on their own computer and returns finished deliverables.

## Goals
Students will be able to:
- Explain the difference between a chat and an agent: the harness, tools, and the tool-use loop.
- Write a task brief with a goal, inputs, constraints, and acceptance criteria.
- Review an agent's plan before it runs, set what it may do without asking, and interrupt or redirect it.
- Read what a task cost in usage and context.
- Review the result against the brief and recover from a wrong turn.

## Session 1 (75 min)
- 20 min: From chat to agent. Why an agent can do what chat cannot: it reads, writes, runs, and checks its own work.
- 15 min: Demo. A messy folder of documents reconciled into a report, with the plan reviewed first.
- 10 min: Delegation skills. Task briefs, acceptance criteria, how much to specify, when not to delegate.
- 30 min: Guided practice: each student delegates a small folder task (organize and index a set of files by rules they write).

## Session 2 (75 min)
- 15 min: Autonomy controls. Plan review, approvals, what the agent may do unasked, irreversible actions. Usage and context: what a task cost.
- 50 min: Lab: the folder-scale assignment.
- 10 min: Share-out. Where did the agent go wrong, and how did you notice?

## Assignment: Folder-scale delegation task
Choose one (or propose your own): reconcile a folder of inconsistent documents and report on conflicts; build a local knowledge repository from web pages and draft a summary from it; clean and combine several data files into a report with charts; produce a set of documents from a template and a table. Submit the task brief, the agent's plan (with your changes), the approvals you gave or refused, the outputs, and a 400-word review memo assessing the result against your acceptance criteria.
- **500 extension:** run the same task twice with different briefs (minimal vs detailed) and compare quality, time, and usage.
- Estimated time: 4 hours.

## Responsible use
File access, irreversible actions, backups, keeping agents out of folders with sensitive data.
