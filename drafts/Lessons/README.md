# COSC-300/500 Applied AI Essentials: Lesson Texts

Full lesson text for each class session (two per week, 30 in all). Each file matches the slide deck of the same name in `../Slides/`, and both are built from `../Draft Outline/`.

## How each lesson is organized
- A header line with the surfaces, capabilities, and 4D focus, all by name.
- "What you will be able to do after this session."
- Numbered sections in the order they are taught, written as prose students can read.
- In Session 2 of each week, the assignment in full, followed by "Before next week."
- Key terms.

## Instructor notes
Every instructor note is a blockquote that begins with **"Instructor note"**:

> **Instructor note: preparation.** ...

Each lesson opens with a preparation note (materials, demos to set up, timing). Other notes sit beside the section they refer to. Everything outside these blockquotes is written for students.

To make a student version, delete every blockquote that starts with `> **Instructor note`. The other blockquotes are example prompts that belong in the student text.

## Before each class
Notes flag claims about products, plans, prices, and eligibility that change quickly. Recheck them the week you teach. Week 13 (Muse) relies on third-party reports that still need checking on Meta's own pages. Weeks 11–12 depend on the API access decision, which is still open.
