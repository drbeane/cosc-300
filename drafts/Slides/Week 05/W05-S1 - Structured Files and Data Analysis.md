## Structured files

Formats people **and** AI both read and write well:

| Format | Good for |
|---|---|
| **Markdown** | Documents, notes, instructions |
| **CSV** | Tables of data |
| **JSON** | Structured records, app data |
| **Mermaid** | Diagrams as text |

---

## Why they matter

- Easy to check, edit, and version
- Move cleanly between tools
- Instruction files and skills (week 7) **are** Markdown
- Ask for these instead of "make it look nice"

---

## Markdown in 30 seconds

```markdown
# Heading
## Subheading
- bullet
**bold**, *italic*
| table | row |
```

---

## Mermaid in 30 seconds

```mermaid
flowchart LR
  A[Question] --> B[Search] --> C[Read] --> D[Report]
```

Ask: *"Draw this process as a Mermaid flowchart."*

## Data analysis with code

- The AI **writes and runs code** on your uploaded data
- It can clean, summarize, chart, and model
- The code is visible: **read it**

---

## Demo: a messy dataset

1. Upload the file
2. Ask for a cleaning plan before any analysis
3. Run the analysis and chart
4. Open the code and catch a wrong aggregation

<!-- Plant a duplicate-ID or mixed-unit issue that produces a wrong average. -->

---

## Check the analysis, not just the chart

- Row counts before and after cleaning
- What was dropped, and why?
- Units and categories
- **Recompute** three numbers yourself
- Does the chart match the table?

## Guided practice

1. Load your dataset
2. Get a cleaning plan; approve or change it
3. Run two analyses
4. Start your verification log

## Responsible use

What may you upload?

- **FERPA**: student records
- **Client and employer data**
- **Confidential information**

If you wouldn't email it to a stranger, don't upload it.
