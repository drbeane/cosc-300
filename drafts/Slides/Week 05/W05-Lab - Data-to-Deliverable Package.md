# Data-to-Deliverable Package
### Week 5 · Lab and assignment
COSC-300/500 Applied AI Essentials

---

## Guided practice

1. Load your dataset
2. Get a cleaning plan; approve or change it
3. Run two analyses
4. Start your verification log

---

## Lab: finish the package

1. **Report**: 2 pages with charts
2. **Deck**: 5 slides
3. **One generated image or diagram**, labeled as AI-generated
4. **Verification log**: 3 numbers recomputed, 1 error caught

---

## Assignment: Data-to-deliverable package

- Dataset: 500+ rows, with some mess
- Report + deck + labeled image or diagram + verification log
- **500 extension:** methods appendix: each analysis step, and one alternative you rejected
- About 4 hours
