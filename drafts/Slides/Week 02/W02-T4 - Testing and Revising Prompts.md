### Week 2

## Test inputs, not vibes

- One good output proves little
- Build **5 test inputs** that cover normal and tricky cases
- Run every prompt version on all 5
- Compare versions on the same inputs

This habit returns in weeks 3 and 12 as **evaluation**.
