## Plugins

- A **bundle** of skills, connectors, and other pieces
- Shared with a team as one unit
- How organizations package "the way we do things"

---

## Skills in chat vs in an agent

| In chat | In an agent with a folder |
|---|---|
| Works on **uploaded copies** | Works on **the real files** |
| Instructions typed in settings | Instruction file **lives with the work** |
| Can't run your tests or tools | Can run scripts, tests, local tools |
| Results downloaded | Results saved in place |

Skills run in chat, but they're **limited** there.

# Lab
## Write and test a skill

---

## Pick a task you do repeatedly

- Formatting a lab report
- Lecture notes → flashcards
- Triaging a downloads folder
- A weekly status update
- Your own idea

---

## Write it

1. **Description**: when should it be used?
2. **Steps**: what to do, in order
3. **Output**: format and location
4. **Rules**: what never to do
5. Supporting files if needed (template, example)

---

## Test it

- Run on **three different inputs**
- Did it trigger when it should?
- Did it follow every step?
- What broke?

**Revise at least once.** Keep a change log.

---

## Share-out

- Put your skill in the **class skill library**
- One thing that surprised you
- The class library feeds the **midterm project**

---

## Responsible use

- Skills are **code-like instructions**
- Read before installing anyone else's
- A skill can tell an agent to do things you didn't intend
- Validate before sharing

---

## Assignment: Write and test a skill

Submit: skill files, 3 test inputs and outputs, change log

- **500 extension:** a classmate uses your skill without help; report what broke and revise
- About 3–4 hours
