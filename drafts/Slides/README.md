# COSC-300/500 Applied AI Essentials: Slide Decks

One Markdown deck per class session (two per week, 30 in all), built from `Draft Outline/`.

## Format
- Slides are separated by `---`. The front matter (`marp: true`) lets the files render directly as slides with the Marp extension for VS Code, and they also read cleanly as plain Markdown.
- Speaker notes are HTML comments (`<!-- ... -->`). Marp shows them as presenter notes; they're hidden in normal Markdown preview.
- Each deck opens with a timed agenda that matches the weekly outline. Assignments and "Before next week" slides close Session 2.

## Before each class
Product details change quickly. Notes marked "verify" or "check" flag slides with plan, model, price, or eligibility claims to recheck that week.
