# Three-Vendor Comparison
### Week 1 · Lab and assignment
COSC-300/500 Applied AI Essentials

---

## Before the lab

- Claude Academy: **AI Fluency: Framework and foundations**, lessons 1–5
- Set up: **Claude Pro**, Maryville **Copilot Chat**, free **NotebookLM**
- Install the **Claude desktop app**
- Pick a task from your own coursework or job for the lab

---

## The lab

1. Pick a realistic task from your coursework or job
2. Run it on **three chat tools**:
   - Claude
   - Copilot Chat
   - one free tool (ChatGPT Free, Gemini, …)
3. Run it on **two Claude models or effort levels**
4. Save every prompt and output

---

## What to compare

- **Accuracy**: is it right?
- **Usefulness**: would you actually use it?
- **Speed**
- **Format and tone**
- **What each tool could and couldn't do** (search, files, length)

Start your comparison table now.

---

## Share-out

- Which output would you actually use?
- Where did the tools differ most?
- Did the bigger model or more effort help, or just cost more?

---

## Assignment: Three-vendor comparison

- One task, three chat tools, two Claude settings
- One-page comparison table
- 400-word evaluation: which output you'd use and why
- Include all prompts
- **500 extension:** relate findings to a published model card or system card
- About 3 hours
